# 🌌 Радиан (Younivector) — Десктопное рабочее пространство

**Радиан** — это современное десктопное приложение, разработанное на связке **Python**, **pywebview** и **PyQt6 (QtWebEngine)** с поддержкой локальной базы данных и модульной архитектуры. Проект спроектирован для кроссплатформенной работы (Linux / Windows) и предоставляет удобное графическое окружение с веб-интерфейсом.

---

## 🛠 Технологический стек

* **Язык программирования:** Python 3.10+
* **Графический интерфейс (GUI):** `pywebview` с принудительным бэкендом **Qt (PyQt6-WebEngine)**
* **Веб-интерфейс:** HTML5, CSS3, JavaScript (модульная структура)
* **База данных:** SQLite / локальное хранилище данных через кастомные модули
* **Управление зависимостями:** `venv` / `pip`

⚙️ Установка и развертывание (Linux / Ubuntu)

Для успешного запуска проекта на Linux-системах (особенно при использовании Snap-версии VS Code или защищенных окружений PEP 668) выполните следующие шаги:
1. Клонирование репозитория и переход в папку
Bash

git clone [https://github.com/reeqwer-cmd/Radius.git](https://github.com/reeqwer-cmd/Radius.git)
cd Radius

2. Создание виртуального окружения
Bash

python3 -m venv .venv
source .venv/bin/activate

3. Установка зависимостей
Bash

pip install --upgrade pip
pip install pywebview PyQt6 PyQt6-WebEngine qtpy bottle proxy_tools

🚀 Запуск приложения

Для запуска приложения в штатном режиме (с обходом ограничений системных библиотек в изолированных средах):
Bash

env -u LD_LIBRARY_PATH python3 Main.py

Отладка в VS Code

В папке проекта уже настроен файл .vscode/launch.json. Вы можете запустить проект через встроенный отладчик, нажав клавишу F5.
💡 Особенности реализации

    Гибридная архитектура: Интерфейс полностью написан на веб-технологиях (HTML/JS), а вся бизнес-логика, работа с файловой системой и БД выполняются на стороне Python через мост js_api=api.

    Стабильность на Linux: Конфигурация принудительно инициализирует QtWebEngine через переменные окружения (QTWEBENGINE_CHROMIUM_FLAGS), что позволяет избежать падений на компонентах WebKitGTK внутри изолированных окружений.
