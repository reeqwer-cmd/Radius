# 🌌 Радиан (Younivector) — Десктопное рабочее пространство

**Радиан** — это легковесное, модульное десктопное рабочее пространство, сочетающее блочный текстовый редактор документов и бесконечную интерактивную доску (**Флипчарт / Edgeless Canvas**). Приложение построено на гибридной архитектуре: современный веб-интерфейс работает внутри изолированного контейнера Chromium под управлением **Python**, **pywebview** и **PyQt6 (QtWebEngine)** с локальным хранением данных в **SQLite**.

---

## 🛠 Технологический стек

### Core & Backend
* **Python 3.10+**: ядро приложения и бизнес-логика.
* **pywebview + PyQt6 (QtWebEngine)**: десктопный рендеринг веб-окружения на базе Chromium без overhead-затрат платформы Electron.
* **SQLite3**: локальное реляционное хранилище с каскадным удалением и хранением документов, флипчартов и пользовательских настроек в формате JSON.
* **pywebview JS API Bridge (`api.py`)**: двусторонний асинхронный мост связи фронтенда и бэкенда.

### Frontend & UI
* **Vanilla JavaScript (ES6+) & HTML5 Canvas / SVG**: кастомный графический движок бесконечного холста без тяжелых внешних фреймворков.
* **Editor.js**: блочный модульный WYSIWYG-редактор с поддержкой заголовков, списков и чек-листов.
* **CSS3 Custom Properties**: динамическая палитра из 14 авторских цветовых тем с плавной сменой состояний.

📖 Руководство пользователя
1. Первичный запуск и рабочие пространстваПри первом старте приложения открывается окно онбординга.Введите название вашей рабочей среды (например, «Основное пространство», «Проект Radius») и нажмите Enter.Название рабочего пространства вверху сайдбара можно переименовать в любой момент: кликните на него, введите новый текст и нажмите Enter (или Esc для отмены).
2. Организация файлов и папокСоздание папки: нажмите кнопку «Создать» в сайдбаре ➔ выберите «Папка» ➔ введите имя и нажмите Ок.Создание документа: выберите в меню пункт «Документ» — создастся классическая заметка на базе Editor.js.Создание флипчарта: выберите в меню пункт «Флипчарт» — создастся бесконечный холст для схем и зарисовок.Быстрое добавление в папку: наведите курсор на папку в дереве и нажмите + (добавить документ) или 🎨 (добавить флипчарт).Сортировка и перемещение (Drag & Drop): захватывайте элементы за маркер ⠿ и перетаскивайте их между папками или меняйте порядок в списке.
3. Работа с модулем «Флипчарт» (Edgeless Canvas)При клике на документ типа «Флипчарт» открывается бесконечный холст с плавающей нижней панелью (Dock):ИнструментХоткейОписание действияКурсор (Select)VРежим выделения. Зажмите ЛКМ на шапке наклейки, чтобы переместить её по доске.Рука (Hand)HПанорамирование. Зажмите ЛКМ на свободном поле (или зажмите колесо мыши) и двигайте холст.Наклейка (Sticky)SВыберите инструмент, затем кликните в любое место поля для создания цветного стикера.Стрелка (Connector)CНаведите курсор на наклейку — по краям появятся 4 точки-порта. Зажмите точку и протяните стрелку ко второй наклейке. Линия привяжется автоматически.Перо (Pen)PСвободное рисование от руки поверх холста и наклеек в выбранном цвете.Ластик (Eraser)—Быстрая очистка всех нарисованных пером линий на доске.МасштабированиеWheelВращайте колесо мыши для плавного зума от 20% до 250%. Кнопка ↺ сбрасывает масштаб к 100%.Изменение размера—Потяните за нижний правый угол наклейки, чтобы изменить её ширину и высоту.
4. Настройки и персонализацияНажмите кнопку «Настройки» внизу боковой панели:Вкладка «Модули»: управление опциональными надстройками (счетчик слов, модули интеграций).Вкладка «Темы оформления»: переключение между 14 контрастными палитрами (Emerald Green, Wasabi, Creased Khaki, Noir de Vigne, Arsenic и др.). Тема применяется мгновенно и сохраняется в SQLite.
